# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — start the dev server (http://localhost:3000, Turbopack)
- `npm run build` — production build (Turbopack)
- `npm run start` — serve the production build
- `npm run lint` — ESLint (`next/core-web-vitals` + `next/typescript`, includes the React Compiler rules)
- `npm run typecheck` — `tsc --noEmit`
- `npm test` — Vitest (pet physics/engine unit tests)

CI (`.github/workflows/ci.yml`) runs `npm ci`, lint, typecheck, tests and build on pushes to `main` and on every PR. Keep all four green.

## Architecture

Personal portfolio (Anthony Lam) on **Next.js 16 App Router + React 19 + TypeScript (strict) + Tailwind CSS v4**. The design direction is **quiet editorial** (see `.impeccable.md`): left sidebar nav, Fraunces display serif for h1/h2, Geist Sans for prose, Geist Mono for metadata, grayscale palette with dark default and a light toggle. The Journey globe is the one expressive centerpiece.

Routes (`src/app/`): `/` (About + Now), `/experience`, `/projects`, `/journey`, `/interests` (+ `/interests/ai`, `/interests/ai/papers/[id]`, `/interests/food`, `/interests/active`), `/resume`, `/api/resume`, `/pet-lab` (dev only; 404s in production), and a custom Null Island 404.

**Content layer:** all portfolio content lives in typed modules under `src/data/` (`profile.ts`, `experiences.ts`, `projects.ts`, `journey.ts`, `interests.ts`, `site.ts`, typed via `types.ts`), consumed via the `@/data` barrel. Pages read from here — never hardcode content in components. Content edits: extend the interface in `types.ts` first, then the data module. Photos are served from a Supabase media bucket (`src/data/media.ts`, uploaded with `scripts/upload-media.mjs`).

**Draft entries:** entries in `interests.ts` with a `draft` note are placeholders. `live()` in `src/components/interests/Items.tsx` filters them out in production, so only real entries ship. Don't invent real-looking content to fill them.

**Resume:** the PDF lives in a private Supabase bucket. `src/app/api/resume/route.ts` signs a short-lived URL server-side (needs `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SECRET_KEY`); `?view` streams it inline for the `/resume` iframe.

### Key components (`src/components/`)

- `Sidebar.tsx` — icon rail nav, theme toggle (`theme.ts` holds the shared `Theme` type and the pre-paint init script).
- `Journey.tsx`, `JourneySteps.tsx`, `JourneyGlobe.tsx` (three.js / react-three-fiber particle-terrain globe, loaded with `next/dynamic`, `ssr: false`), `PhotoCarousel.tsx`, `useStepKeys.ts` — the scroll-paged Journey page. Globe data is generated by `scripts/generate-globe-data.mjs` into `public/globe/`; camera math is in `src/lib/globe.ts`.
- `SmoothScroll.tsx` — Lenis smooth scrolling; skipped under reduced motion. `scrollToY()` is the shared way to scroll programmatically.
- `interests/` — card components and `sections.ts`, which composes the Interests pages from `src/data/interests.ts`.
- `useReducedMotion.ts` — `prefers-reduced-motion` as a hook; use it instead of calling `matchMedia` in effects.

### The pixel pet (`src/components/pet/`)

A canvas pixel-art pet (cat, dog or bunny) that walks on page elements, jumps between them, can be picked up and thrown, and plays fetch. It mounts globally from `layout.tsx` through `PetMount.tsx`.

- `engine.ts` — DOM-free brain and physics (`PetEngine`). `ball.ts` is the fetch ball; `physics.ts` holds gravity, `landing`, `clamp`, `Surface`.
- `surfaces.ts` — collects the page elements the pet can stand on (`data-pet-platform` opts in, `data-pet-ignore` opts out) and caches their geometry.
- `Pet.tsx` — render loop and input. `preferences.ts` — `usePetPreference()` store (species, coat, on/off) persisted in `localStorage`; `?pet=dog&coat=black` overrides it.
- `sprites/` — sprite frames authored as 16×16 text, one file per species; `sprites/index.ts` holds each species' animations and traits (walk speed, jump height, fetch move). Per-species behaviour belongs in those traits, not in `if (species === …)` checks.
- `PetLab.tsx` (+ `/pet-lab`) — review page for sprites, dev only. `scripts/pet-sheet.mjs <species>` renders a contact sheet and validates frame size and palette. `sprites/sprites.test.ts` checks that every animation's frames exist and every frame is 16×16 with valid palette characters, so keep it passing when adding a species.
- Nothing in the UI dispatches `THROW_BALL_EVENT` yet; the dev-only `B` key does. The paw menu / picker UI is not built.

### Conventions worth knowing

- **Tailwind v4, CSS-first config.** No `tailwind.config.js`. Tokens are CSS variables plus `@theme inline` in `src/app/globals.css` (`bg-background`, `text-foreground`, `bg-surface`; `light:` variant for the few spots tokens can't cover).
- **React Compiler lint rules are on** (the compiler itself isn't enabled). No setState synchronously in an effect, no assigning to props or memoized values, no ref reads during render. For browser state (media queries, devicePixelRatio, localStorage) use `useSyncExternalStore`. For per-frame mutable state in the globe, use a small class with methods (`View`) and the `setUniform` helper in `JourneyGlobe.tsx`, not direct assignment.
- **Accessibility:** honour `prefers-reduced-motion` everywhere that animates.
- **No fabricated content.** Pages only say what `src/data` contains.
- **`DESIGN.md` is a historical record** of a chat "digital twin" design that was never built. It is not the current design; `.impeccable.md` is.
- **`portfolio-claude-code-prompt.md`** is the original prompt for a retired IDE-style design. Ignore it.
- **Git history:** earlier explorations live on branches (`ide-portfolio-backup`, `redo`, `agent-portfolio-backup`). Don't resurrect without asking.
