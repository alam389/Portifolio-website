# Impeccable Design Config

## Design Context

### Users
Broader and personal: recruiters and engineers still do a quick first scan and
then read project write-ups, but the site is also for friends, collaborators and
anyone following Anthony's journey, interests and writing. Desktop-primary;
mobile must hold up.

### Brand Personality
Real, meticulous, quietly confident. The target reaction is **"this is a real
person who builds carefully."** Technical credibility and warmth over visual
drama; personality shows up in small, earned moments (e.g. the Null Island 404),
never as gimmick.

### Aesthetic Direction
**Quiet editorial.** The IntelliJ/IDE metaphor is retired. Current build: left
sidebar nav, Fraunces display serif (SOFT 50) for h1/h2 with Geist Sans for prose
and Geist Mono for metadata, generous space, dark default plus a light toggle.
The palette is currently pure grayscale (`--background` #0a0a0a / #fafafa);
one expressive centerpiece, the Journey particle-terrain globe, carries the
visual interest.

**Open exploration: editorial cyberpunk / coding themes.** Anthony wants to
explore this direction for color and mood. Not decided. Candidate shape: keep the
editorial typography and restraint, add a coding-flavored accent system (terminal,
syntax and neon-on-dark cues) used sparingly. The prior anti-reference "neon cyan/
purple gradients" conflicts with a naive cyberpunk take, so any exploration should
be flat, high-contrast accents rather than gradients or glow-everything.

**Anti-references:** neon gradients, glassmorphism, gradient text, generic template
portfolios, stock IDE skins.

### Design Principles
1. **Content is the hero** — chrome and color amplify the writing, never obscure it.
2. **Restraint with one centerpiece** — stay quiet everywhere else so the globe (and any accent) lands.
3. **Personality in small moments** — a clever 404 or a pin, not decoration on every surface.
4. **Color is intentional** — grayscale by default; any accent is flat, sparing and tied to meaning (active state, links, pins).
5. **Accessible always** — WCAG contrast, `prefers-reduced-motion`, native semantics.
