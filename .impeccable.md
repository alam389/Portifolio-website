# Impeccable Design Config

## Design Context

### Users
Recruiters doing an 8-second first scan, then engineers/hiring managers reading
project write-ups in depth. Desktop-primary; mobile must hold up (drawer, breadcrumb).

### Brand Personality
Real, meticulous, quietly confident. The site should feel like the workspace of
someone who lives in an editor — the target reaction is **"this is a real engineer."**
Technical credibility above visual drama; never gimmicky.

### Aesthetic Direction
**IntelliJ New-UI metaphor** (pivoted from VS Code at Anthony's request — IntelliJ is
his real daily IDE), executed with authentic depth: main toolbar (project chip, branch
widget, run config), Project tool window, bottom-underline tabs, blue selection rows,
status bar, gutter line numbers, syntax-token headings, decorative minimap.
**JetBrains New-UI dark palette** (editor `#1e1f22`, panels `#2b2d30`, blue `#3574f0`
accent) with Darcula-style code colors (salmon keywords, green strings, purple JSON
keys); IntelliJ Light as the toggle theme.
**Anti-references:** stock blue-gray VS Code default (too plain), neon cyan/purple
gradients, glassmorphism, gradient text, generic template portfolios.
Fonts: Geist Mono for chrome/headings/code, Geist Sans for prose body.

### Design Principles
1. **Authenticity over decoration** — only add details a real editor genuinely has.
2. **Content is the hero** — chrome amplifies the writing, never obscures it.
3. **Color comes from the syntax palette** — accents are token colors, applied with intent.
4. **One choreographed moment** — boot intro + staggered load, then stillness.
5. **Accessible always** — WCAG contrast, `prefers-reduced-motion`, native semantics.
